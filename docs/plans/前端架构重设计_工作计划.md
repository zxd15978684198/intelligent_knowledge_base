# PyKnora 前端架构重设计 · 工作计划

> **For agentic workers:** 本计划先交付「设计文档 + 阶段拆分」，代码重构按阶段计划执行；执行阶段用 `subagent-driven-development`（推荐）或 `executing-plans`。步骤用 `- [ ]` 跟踪。
> 定位：**工作计划**，不是设计文档本身。按仓库既有 `docs/plans/` 约定落盘，不新建 `docs/superpowers/plans/`。

**Goal:** 把 `web/` 从 P0 演示版重新设计为面向生产的前端架构，产出一份完整设计文档，再按文档分阶段重构代码、验收、更新进度文件。

**Architecture:** 以「分层与模块边界」为主轴组织设计文档（现状 → 目标架构 → 路由渲染 → 状态数据流 → 契约层 → 鉴权会话 → 可观测性/交付/演进 → 迁移回滚验收）。鉴权 Cookie 化只是其中**一章**，四处已确认决策压成一节，不再展开成独立施工 spec。执行顺序 `P1 鉴权 → (P3 可观测性 ∥ P4 交付加固) → P2 取数上移`。

**Tech Stack:** Next 16.4.3（App Router、`output:"standalone"`）/ React 19.3.1 / TypeScript 5.9 / pnpm 12.6.0 / TanStack Query v5 / Tailwind v4 / Zod 4 / Vitest 3 + MSW 2 + Playwright 1.56 + axe-core；后端 FastAPI + PG16 + uv（Python 3.12）。

- `AGENTS.md` 三条硬规则：每阶段必改进度文件（`docs/IMPLEMENTATION_STATUS.md` 顶部「本轮」段 + `docs/plans/成员任务进度表.md` §9）；先读再写，不重构/不删已有功能/不动别人目录；证据先于结论，没跑过的命令不写「通过」。
