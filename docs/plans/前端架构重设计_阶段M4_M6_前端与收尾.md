## 4. 接口约定

- 令牌参数三态：省略 = 会话 Cookie（带凭据 + CSRF 头）；显式空值 = 匿名登录端点；字符串 = Bearer 兼容通道。
- 401 单飞：并发只放出一个刷新请求，其余挂同一 Promise；成功后原请求重放一次；失败统一跳登录。
- 刷新请求自身必须带 CSRF 头；CSRF 值按会话稳定、不随刷新轮换，重放时重新读取仍有效。
- 流式应答建流前 401 不重放，按既有事件约定发错误事件并等结束事件。

- 端到端：登录成功断言会话 Cookie 存在且脚本不可读；刷新页面仍登录；两个标签页并发只触发一次刷新。
