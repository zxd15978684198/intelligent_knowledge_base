# PyKnora 前端升级计划（视觉重构 · 高端克制 SaaS）

> 目录名按需求原文用 `fronted`。本计划与 `docs/plans/fronted/前端DAG执行路径.md` 配套：本文件管**改什么、为什么**，DAG 文件管**谁先谁后、怎么并行**。
> 技能依据：`redesign-existing-projects`（Scan → Diagnose → Fix），只升级不重写，功能零回归。
> 状态：**已定稿执行**（风格/深度/深色模式三项决策由用户拍板，见 §0）。

---

## 0. 定位与三项决策

| # | 决策 | 选定 | 影响 |
|---|---|---|---|
| D1 | 风格方向 | **高端克制 SaaS**（Linear/Stripe 式） | 灰阶精细化、品牌色沉稳、排版强对比、微交互；专业工具感 |
| D2 | 改动深度 | **视觉层 + 交互细节润色** | 布局骨架不动；hover/pressed/loading/empty/error/动效补齐 |
| D3 | 深色模式 | **只做浅色** | tokens 单主题；验收一遍过 |

范围：`web/` 全部 9 个路由、17 个 `components/ui/*`、`app-shell`、`features/*` 的展示层。
**不动**：`lib/api/`、`lib/contracts/`、features hooks 数据逻辑、后端契约、布局骨架、测试的行为语义。

## 1. 现状审计（六轴诊断，每条钉到代码）

### 1.1 排版（Typography）

| # | 问题 | 证据 | 修法 |
|---|---|---|---|
| T1 | **Inter 打天下，无个性**（skill 头号反模式） | `globals.css:50-52` `--font-sans` 首选 "Inter" | 换 **Geist**（`next/font` 自托管，**不引 CDN**——`/docs` 曾被 cdn.jsdelivr 挂掉的教训）；标题字族可选配 Geist Mono 强化工具感 |
| T2 | 标题缺存在感 | `kbs/page.tsx:33` `text-2xl font-semibold`，无负字距、行高未收 | display 级标题加 `tracking-tight`（-0.02em）+ `leading-tight`；页面 h1 提到 `text-[28px]/[32px]` |
| T3 | 层级只靠 Regular/Semibold 两档 | 全仓 `font-medium`/`font-semibold` 为主 | 引入 400/450/500/600 四档（Geist 可变字重），小标签用 500 + 正字距 |
| T4 | 段落宽度与行高可再放开 | `max-w-2xl text-sm` 行高未设 | 正文 `leading-relaxed`（1.625~1.75），段宽 65 字符左右（约 `max-w-[65ch]`） |
| T5 | 数字已 tabular（✅ 保留） | `globals.css:93-95` `.tabular` | 不动；表格数字列继续用 |

### 1.2 色彩与表面（Color & Surfaces）

| # | 问题 | 证据 | 修法 |
|---|---|---|---|
| C1 | **卡片=白底+1px 边框，零阴影**——正是 skill「Generic card look」反模式 | `card.tsx:13-19` 注释明写「不用阴影堆叠」 | 换**着色阴影**（冷调、低透明度，光源统一左上）：`--shadow-sm/md/lg` 三级令牌；卡片默认 `shadow-sm`，浮层 `shadow-lg` |
| C2 | canvas 与 surface 对比太弱（#f5f7f8 vs #fff） | `globals.css:13-14` | canvas 压到更冷的 `#f4f6f8`，surface 保持纯白，卡片靠阴影浮起而非边框 |
| C3 | 强调色单一但「平」 | `--color-primary: #0f5964` | **保留青（品牌记忆）**但沉稳化：primary 提亮半档 `#126572`、hover `#0d4c57`；新增 `primary-ring` 供焦点环 |
| C4 | 状态色可用但弱块感 | `success/warning/danger/info` + weak 后缀 | 保留语义，weak 面饱和度 +5%，配图标（已有「不能只靠颜色」规则，保留） |
| C5 | 圆角偏小偏硬 | `--radius-*: 4/6/10px` | 阶梯放大：`sm 6 / md 10 / lg 16`，浮层与卡片用 lg，内元素用 sm，**同一容器内不混档** |

### 1.3 布局（Layout）——只做允许的微调（D2 边界内）

| # | 问题 | 修法（不重排骨架） |
|---|---|---|
| L1 | 页面内容与 canvas「贴」在一起，留白不足 | 页面级间距 6→8（24→32px），页头与内容区之间加呼吸区 |
| L2 | 页头说明文字偏长、视觉重 | 说明文字改 `text-[13px] text-fg-muted leading-relaxed`，默认折叠次要说明（可展开） |
| L3 | 表格行高密、扫读累 | 行高 44→48px，斑马纹改「hover 行浮起」，数字列右对齐 |
| L4 | 窄屏 `/kbs` 表格「被裁」（旧账，被测成 1117>1024、845>390） | **实测校正（2026-11-04，`.tmp-measure-widths.mjs` 三档真浏览器）**：`pageOverflow` 在 1440/1024/390 **全为 0**；`Table` 外层 div 本就 `overflow-x:auto` 且 `app-shell` 主列 `min-w-0` 生效；把容器滚到最右后最后一列都在容器内可到达（1024：991≤992；390：365≤366）。旧账量的是滚动容器**内** `<table>` 自身宽度，把它当"被裁"是误判 → 本轮**不做卡片化/不重排**（D2 已排除），改为：① 三档宽度断言固化进 e2e（N7）；② 补窄屏「可横向滚动」可发现性提示 |

### 1.4 交互与状态（Interactivity）

| # | 问题 | 修法 |
|---|---|---|
| I1 | hover 只有 background shift | 按钮 hover 加 `translate-y-[-1px]` + 阴影过渡；active `scale-[0.98]`（已有部分，统一） |
| I2 | 过渡只有 `duration-150` 一档 | 建 motion 令牌：`--motion-fast 150ms / --motion-base 220ms / --motion-slow 320ms`，只动 `transform/opacity`（GPU） |
| I3 | 无入场动效 | 卡片/表行 stagger 入场（`opacity + translateY(6px)`，间隔 30ms，`prefers-reduced-motion` 自动关） |
| I4 | 骨架屏单调 | 骨架加微光扫过（shimmer，1.2s 循环）；EmptyState 加主行动按钮的视觉锚点 |
| I5 | 焦点环已有（✅ 保留） | `globals.css:79-82` 不动，只换色值引用 `primary-ring` |

## 2. before → after 令牌映射（`globals.css` 的 `@theme`，改值为主、改名为辅）

| 令牌 | before | after | 说明 |
|---|---|---|---|
| `--font-sans` | Inter… | **Geist**, "PingFang SC", … | `next/font` 自托管；中文回落不变 |
| `--color-canvas` | `#f5f7f8` | `#f4f6f8` | 拉开与 surface 的差距 |
| `--color-primary` | `#0f5964` | `#126572` | 保留青系、沉稳提亮 |
| `--color-primary-hover` | `#0b4750` | `#0d4c57` | 随 primary 校 |
| `--color-primary-ring` | （无） | `#126572` + 2px/2px-offset | 焦点环独立令牌 |
| `--radius-sm/md/lg` | 4/6/10px | **6/10/16px** | 柔和阶梯 |
| `--shadow-sm` | （无） | `0 1px 2px rgba(23,34,37,.05), 0 1px 3px rgba(23,34,37,.04)` | 卡片默认 |
| `--shadow-md` | （无） | `0 2px 4px rgba(23,34,37,.05), 0 12px 24px -8px rgba(23,34,37,.08)` | 悬浮面 |
| `--shadow-lg` | （无） | `0 4px 8px rgba(23,34,37,.06), 0 24px 48px -12px rgba(23,34,37,.12)` | Dialog/Toast |
| `--motion-fast/base/slow` | （无，散写 150ms） | `150/220/320ms` | 只配 transform/opacity |
| `--spacing-hit` | 2.75rem（44px） | 不变 | 触控下限（无障碍红线） |

**红线（继承既有，不得回退）**：① 组件只许引用语义令牌，禁止字面色值；② 正文对比度 ≥4.5:1（`fg-subtle: #5f7175` 的注释就是当年 axe 判 serious 的教训，axe 五路由当门禁）；③ `:focus-visible` 必须可见；④ `prefers-reduced-motion` 全局降级；⑤ 状态必须「色+图标/文字」双通道。

## 4. 明确不做（防止范围蔓延）

1. 不重排页面骨架（侧栏/顶栏结构、路由、信息架构保持）。
2. 不做深色模式（D3）。
3. 不引新 UI 组件库、不引动画库（Tailwind v4 原生 + 手写 keyframes 足够）。
4. 不动 `lib/api/`、`lib/contracts/`、hooks 数据逻辑、后端接口。
5. 不换图标库（Phosphor 保留）。
6. 不做 marketing 式落地页/英雄区（这是工具，不是官网）。
7. 图片/插画不引外链素材（CDN 教训），纯 CSS 质感（阴影/渐变/噪点以内存为准）。
