## 0. 一句话结论

**候选不优于基线，本轮判「候选不采用」。** 唯一主因素 `retrieval_strategy`
（baseline → candidate）带来的净变化是：Recall@5 / Precision@5 **零变化**（+0.000）、
引用准确率 **−0.037**（0.356 → 0.318）、无证据拒答准确率 **−0.333**（0.667 → 0.333）、
检索 P95 −163.4 ms、问答 P95 +245.2 ms；逐样本口径 **退化 4 条 / 改善 1 条**。
按本文件 §4 的规则（退化条数 > 改善条数 → 只能判"不采用"）与计划 §10.2 第 2 条硬门槛
（`no_evidence` 3 条全 `ABSTAINED` 且 `citations=[]`，基线 2/3、候选 1/3，两侧都不成立），
结论是**明确否定**，不是"数据不足、待定"。

### 1.2 三条必须连读的读法警告

1. **检索 P95 的两端不是同一种操作**：基线 375.14 ms 落在 `fact-01`（一次真实检索）；
   候选 211.75 ms 落在 `deny-01`（权限 404 早退，`results=[]`，根本没检索）。
   因此 `−163.4 ms` **不能**读成"检索快了一倍"。作为参照（两个数都在 `raw.jsonl`）：
   两轮里最慢的一次真实检索是基线 `syn-01` 的 551.26 ms、候选 `exact-04` 的 284.13 ms。
2. **问答 P95 由上游 LLM 主导**：两轮 TTFT 都在 5.0–5.1 s，总时长 5.6–5.8 s，而检索只在 0.2–0.6 s；
   `+245.2 ms`（+4.4%）落在上游端到端抖动范围内，`eval/results/README.md:177-178` 亦如此记录。
3. **`repeats=1`**：每一行的绝对值都只有一次观测，`metrics.*.min == max`，"波动"信息为 0；
   本表能说明"这一轮差在哪"，不能说明"差多少"或"是否稳定"。

## 5. 判定（计划 §5.4 + §10.2 + §11 R3）

第 2 条要读准：两侧的**内容**都没有编造（`noev-02/03` 正文都明说"资料中没有…"），
不合格的是**契约信号**（`status` 没落成 `ABSTAINED`、`citations` 非空）。所以这是
"口径不合格"，不是"安全性变差"；但它确实让候选在硬门槛上比基线更差。

### 5.3 计划 §11 R3 的精确适用（`docs/plans/…:720`）

R3 原文：「对比表同时看 Recall 与 P95；若 **Recall 提升 <2% 而 P95 +50%**，判『不值得』」。

- 前半成立：Recall 提升 0 < 2%；
- 后半**不成立**：检索 P95 是 **−43.6%**（211.75/375.14−1），问答 P95 只有 **+4.4%**，
  没有任何一路 +50%；
- 结论：R3 是**合取**条件，本轮逐字**没有触发**。所以判定不能引用 R3 当"门柱"，
  只能走 §5.1 的三条（主指标零收益 + 退化>改善 + 硬门槛更差）。R3 的实际含义也一样：
  它的前提是"Recall 有提升"，而本轮连提升都没有——比 R3 描述的情形更不划算。

### 5.4 最终判定

> **候选不优于基线。判：本轮不采用 `retrieval_strategy=candidate`，维持 `baseline`。**

三条理由（缺一不可）：① 主指标零收益（Recall/Precision 都是 +0.000，Recall 已在天花板）；
② 退化 4 > 改善 1，其中引用准确率 −0.037、无证据拒答准确率 −0.333 都能落到具体样本
（§4.1）；③ §10.2 第 2 条硬门槛从 2/3 掉到 1/3。

**"不能判定"的边界（缺什么就说缺什么）**：

- 不能判定"候选在任何情形下都更差"——本轮只测了 `top_k×4` 一档倍数、一个 20 条评测集、
  A 区 3 篇语料；要判"候选池放大整体无益"需要 `repeats ≥ 3`、更大评测集、以及多档倍数（如 ×2）。
- 不能判定"引用准确率下降是 `snippet` 500 字截断导致的"——`raw.results[].content` 只有 120 字预览，
  无法区分"片段本身没有事实"与"事实被切在 500 字之外"（需回 `chunks` 表读全文，见 05 §5.3）。
- 不能判定"`noev-03` 变 COMPLETED 是门控阈值问题还是模型自述"——需要门控的 `signals` 明细
  （`raw` 未落盘该字段）。

以上三条都属"机制待定"，**不影响 §5.4 的判定**：判据是"退化必须记 + 退化>改善 + 硬门槛"，
这三条证据是齐的。
