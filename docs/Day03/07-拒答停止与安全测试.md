## 2. `RunStatus`：线上只有 5 个值

`src/pyknora/schemas/chat.py:55-87`，`StrEnum`：`COMPLETED` / `ABSTAINED` / `TIMEOUT` /
`BUDGET_EXCEEDED` / `FAILED`（五值在 `:73-87`）。

**刻意没有 `RUNNING` 与 `CANCELLED`**（该 enum 的 docstring `:56-71` 写明理由）：

| 讲义/计划状态 | 本项目 | 原因 |
| --- | --- | --- |
| `RUNNING` | 无此值 | 流内状态，不发事件；首个 `token` 之前客户端只知道「还没 done」 |
| `CANCELLED` | **无此值**（与计划 `:566` 的映射不一致） | 客户端断开后没人接收 `done` 事件，写一个送不到的枚举值等于自欺 |

> 可观测的等价物是「`budget.cancel()` 后不再检索 + 流断开」。需在验收时决定：
> a) 补 enum 并只在测试里构造；b) 改计划表登记偏差。**本文件不擅自裁决。**
> 影响范围：SAFE-10「用户取消」的终态断言（§4.2）没法写，只能断言「取消后不再检索」。

`DoneEvent`（`schemas/chat.py:90-126`）必填 `status`（`:102-104`）与 `run_id`（`:106-111`）；
